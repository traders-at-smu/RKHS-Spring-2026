raw data → data_loader.py → kernel-ready inputs
                               ↓
    ┌──────────── STAGE 1: Per-Kernel KRR ────────────┐

    │  Macro → KRR ──→ pred_macro[t]                   │
    │                                                   │
    └──────────────────────────────────────────────────┘
                               ↓
    ┌──────────── STAGE 2: ElasticNet Combiner ────────┐
    │                                                   │
    │  [pred_lob, pred_vpin, pred_kyle,                │
    │   pred_hawkes, pred_vrp, pred_macro]             │
    │        ↓                                          │
    │   ElasticNet (walk-forward CV)                    │
    │        ↓                                          │
    │   combined_prediction[t]                          │
    │   (currently ≈ 0 — elastic-net zeros all weights) │
    │                                                   │
    └──────────────────────────────────────────────────┘
                               ↓
    ┌──────────── SIGNAL EXTRACTION ───────────────────┐
    │                                                   │
    │  Kalman Filter (aggressive Q = 10x auto)         │
    │        ↓                                          │
    │  filtered_signal[t]                               │
    │        ↓                                          │
    │  s-score = (signal - μ) / σ                      │
    │        ↓                                          │
    │  Regime-conditional thresholds:                   │
    │    Trending: entry ±0.50, exit ±0.15, TP ±1.50   │
    │    Choppy:   entry ±0.50, exit ±0.15, TP ±1.50   │
    │        ↓                                          │
    │  positions[t] ∈ {-1, 0, +1}                      │
    │                                                   │
    └──────────────────────────────────────────────────┘
                               ↓
    ┌──────────── GATES ──────────────────────────────┐
    │                                                   │
    │  MomentumGate (Arjan):                           │
    │    gate(t) ∈ (0,1) from TSMOM + vol-scaled       │
    │    momentum + EMA cross → Schur product on       │
    │    K_slow before combining with K_fast            │
    │                                                   │
    │  EventProximity:                                  │
    │    gate(t) ∈ (0.5, 1.0) from proximity to        │
    │    FOMC/CPI/NFP/OpEx → attenuates signal         │
    │    near scheduled events                          │
    │                                                   │
    └──────────────────────────────────────────────────┘
                               ↓
    ┌──────────── EVALUATION ─────────────────────────┐
    │                                                   │
    │  Daily resolution (collapsed from bar-level)     │

    │  Walk-forward: 8 expanding folds, 100-bar embargo│

    analytics/ (MC fan, stress test, scorecard)
