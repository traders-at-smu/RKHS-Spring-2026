TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════

  Q: All kernel weights are zero?
  A: Set TUNE_KERNELS=1 and POSITIVE_WEIGHTS=0. Tuning finds the right
     lengthscale for Macro (ℓ=0.1), and allow-neg lets -0.024 through.

  Q: Only 2 trades?
  A: Set WARMUP_DAYS=0. The 120-day default zeros the first 30% of the
     backtest where most trades occur.

  Q: VannaCharm disrupts ElasticNet?
  A: Set SKIP_KERNELS=VannaCharm until v2 restructure. Adding a 7th
     kernel with weak signal shifts regularization and zeros Macro.

  Q: Sharpe doesn't match results_table.txt?
  A: The original Run 13 (Sharpe 1.55) was from a code state we can't
     reproduce (no git history). Run 14 at Sharpe 1.42 is the best
     reproducible configuration. Always use explicit env vars.
